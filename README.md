# 내 자산 포트폴리오 v71

압축 안의 파일을 기존 GitHub Pages 저장소 루트에 덮어쓴 뒤 커밋하세요.
설치 앱은 완전히 닫았다가 다시 여세요. 보유자산과 설정은 유지됩니다.
Apps Script는 기존 v16을 사용하며 재배포할 필요가 없습니다.

추가 투자금 배분 팝업
- 원화: +50만원 / +100만원 / +300만원 버튼을 누를 때마다 현재 투자금에 추가.
- 달러: +500달러 / +1,000달러 / +3,000달러로 버튼 변경. 센트 단위 입력 가능.
- 통화 전환 시 현재 투자금을 저장된 USD/KRW 환율로 환산.
- 종목별 매수 주수를 숫자로 입력하거나 −/+ 버튼으로 조정. 0주 입력 가능.
- 수정한 주수를 기준으로 매수 합계·잔액·예상 비중 즉시 갱신.
- 직접 조정한 주수는 투자금/통화 변경 후에도 유지. ‘자동 배분으로 복원’으로 초기화.
- 예산 초과 시 부족한 금액 표시. 목표비중 초과 시 해당 비중과 안내 표시.
- 기타 종목을 펼쳐 자동 배분에서 0주인 목표 설정 주식도 직접 조정 가능.

자동 배분은 목표비중까지 부족한 금액에 비례하며 국내·미국 주식/ETF를 1주 단위로 계산합니다.
현금/암호화폐/수동자산은 총자산에 포함하고 주식 매수 목록에서는 제외합니다.
저장된 시세·환율 기준, 수수료·환전 비용 제외. 계산만 수행하며 보유 내역을 변경하지 않습니다.
