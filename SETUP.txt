v64 / Apps Script v16

GitHub 업로드
1. 압축을 풀고 폴더 안의 파일을 기존 저장소 루트에 덮어씁니다.
2. 기존 index.html, sw.js, manifest.webmanifest와 아이콘을 포함해 모두 커밋합니다.
3. 기존 GitHub Pages 주소를 열고 새로고침합니다. 상단 v64 표시를 확인합니다.
4. 설치한 앱에서도 완전히 닫은 후 다시 열어 v64를 확인합니다.

기존 주소와 같은 브라우저에서 업데이트하면 보유자산과 설정을 그대로 사용합니다.
앱 캐시는 v64로 갱신되며 저장된 자산(localStorage)은 삭제하지 않습니다.
Apps Script는 v16 그대로입니다. Apps Script 재배포는 필요하지 않습니다.

변경사항
- 일부 시세 조회 실패에도 일일수익금액/수익률 표시.
- 현재가 및 전일종가 마지막 정상값 보존, 계산 종목 수와 기존 시세 표시.
- 종목 수정 및 클라우드 동기화 시 전일종가 유지.
- 긴 종목명은 작은 글자 대신 넓은 영역에 읽기 쉬운 크기로 표시.
- 평가금액, 손익, 수익률, 필터, 설정, 자산변화의 글자 크기와 대비 개선.
- 종목 카드의 수량/평균/현재를 줄별로 표시, 목표비중 줄바꿈 허용.

버전 규칙
앞으로 프로그램 변경마다 버전을 1 증가시킵니다: v64 → v65 → v66.
APP_VERSION, 화면 버전, title, sw.js 캐시명, ZIP 파일명을 함께 갱신합니다.
기존 localStorage 키와 설치 주소는 유지합니다.
