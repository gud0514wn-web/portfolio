# 내 자산 포트폴리오 v70

압축 내부 파일을 기존 GitHub Pages 저장소 루트에 덮어쓴 뒤 커밋하세요.
포트폴리오 탭 맨 아래의 ‘추가 투자금 배분 계산’ 버튼으로 목표비중에 맞춰 살 주식 수를 확인합니다.
투자금 입력 또는 50만/100만/300만원 버튼 → 종목별 계좌·매수 수량·예상 금액·매수 후 비중·잔액 표시.

계산은 새로 들어온 돈을 전체 포트폴리오에 더한 뒤, 목표비중보다 부족한 국내·미국 주식/ETF에 배분합니다.
설정된 목표비중을 그대로 사용하고, 매도 없이 1주 단위로 계산합니다.
남는 돈은 잔액으로 표시하며 기존 보유 내역을 변경하지 않습니다.
현금/암호화폐/수동자산도 총자산과 목표비중 합계에 포함하지만 주식 매수 목록에서는 제외합니다.
시세와 환율은 현재 저장된 값이며 수수료·환전 비용은 제외합니다.
미국 주식의 환산 금액은 1주마다 원 단위로 올림합니다.
Apps Script는 기존 v16을 사용하며 재배포할 필요가 없습니다.
