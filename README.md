그래프 선택 정보 겹침 수정
최고/오늘 옆의 다른 날짜를 선택했을 때, 기존 금액 배지가 선택한 동그라미에 겹치던 문제를 수정했습니다.
배지 위치를 정할 때 선택한 동그라미, 연결선, 선택 정보창, 그래프 선과 막대를 함께 피합니다.
선택 중 가까운 위치에 배치를 못 하는 기존 배지는 잠시 숨기고, 선택을 닫으면 다시 표시합니다.
기존의 모든 동그라미 금액/날짜 조회, 터치/키보드 조작, 투자금 배분 기능은 유지합니다.
