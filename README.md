# 내 자산 포트폴리오 v72

압축 안의 파일을 기존 GitHub Pages 저장소 루트에 덮어쓴 뒤 커밋하세요.
설치 앱은 완전히 닫았다가 다시 여세요. 보유자산과 설정은 유지됩니다.
Apps Script는 기존 v16을 사용하며 재배포할 필요가 없습니다.

자산변화 그래프
- 최저·최고·오늘 금액을 흰색 배지로 표시하고 점 가까이에 배치합니다.
- 선·막대·동그라미와 숫자 간 충돌을 확인하고, 짧은 연결선으로 해당 점을 나타냅니다.
- 어떤 동그라미든 누르면 정확한 원화 금액과 날짜가 나옵니다.
- 선택한 점의 기존 금액 배지는 잠시 숨겨 중복을 방지합니다.
- 다른 금액 배지와 선택 정보도 서로 겹치지 않게 배치합니다.
- 같은 점을 다시 누르거나 그래프 바깥을 누르면 선택 정보가 닫힙니다.
- 키보드 방향키/Home/End로 점을 선택할 수 있고 Escape로 닫습니다.

v71의 누적 금액 버튼, 원화/달러 투자금, 매수 주수 직접 조정 기능을 유지합니다.
