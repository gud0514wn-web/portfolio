모바일 자산관리 v2 설정 안내
============================

1) 시세·환율 자동/수동 새로고침 설정
- apps_script_price_proxy.gs 파일을 Google Apps Script 새 프로젝트에 붙여넣습니다.
- [배포] > [새 배포] > [웹 앱]
  · 실행 사용자: 나
  · 액세스 권한: 모든 사용자
- 배포 후 주소가 .../exec 로 끝나는 URL을 복사합니다.
- 자산관리 앱 > 백업·설정 > "Google Apps Script 시세·환율 API URL"에 붙여넣고 저장합니다.
- 상단의 [↻ 시세·환율] 버튼을 누르면 현재가와 USD/KRW 환율이 갱신됩니다.
- "앱을 열 때 자동 시세·환율 새로고침"을 켜면 실행할 때 1회 자동 갱신됩니다.

- 암호화폐: BTC/KRW

2) 삼성 인터넷 홈 화면/앱 설치
- 단일 HTML을 휴대폰 파일에서 file:// 로 여는 방식은 PWA 설치 조건(HTTPS + Service Worker)을 충족하지 못합니다.
- mobile_portfolio_pwa 폴더 전체를 GitHub Pages, Netlify, Cloudflare Pages 등 HTTPS 정적 호스팅에 올려야 합니다.
- HTTPS 주소로 삼성 인터넷에서 접속한 뒤 메뉴의 [앱 설치] 또는 [홈 화면에 추가]를 누릅니다.
- 이 패키지에는 manifest.webmanifest, sw.js, 192/512 아이콘이 포함되어 있어 그대로 올리면 됩니다.

3) 데이터
- 보유내역은 브라우저 localStorage에 저장됩니다.
- 기기 변경/브라우저 초기화 전에 JSON 백업을 권장합니다.
- 기존 v1 데이터를 같은 브라우저에서 열면 종목코드가 자동으로 보강됩니다.

주의
- 시세·환율 데이터는 개인 자산 관리 편의를 위한 공개 데이터 소스 기반이며 증권사 체결가/정산가와 차이가 날 수 있습니다.
- Yahoo/Naver/CoinGecko의 공개 엔드포인트 변경 시 프록시 코드를 수정해야 할 수 있습니다.


[환율 자동조회]
상단 '↻ 시세·환율' 버튼은 미국/국내/비트코인 시세와 USD/KRW 환율을 함께 갱신합니다.
설정의 '환율만 새로고침'을 누르면 환율만 따로 갱신할 수도 있습니다.
환율은 Yahoo Finance를 우선 사용하고 실패 시 Frankfurter 일일 환율로 대체합니다.

[조회 실패 개선 - v4]
- 국내 종목/ETF는 네이버 시세 경로를 3단계로 자동 재시도합니다.
  1) 모바일 Basic API
  2) 국내 실시간 API
  3) Polling API
- 영문이 섞인 신규 ETF 종목코드도 실시간 API로 재시도합니다.
- 비트코인은 CoinGecko 실패 시 Upbit로 재시도합니다.
- USD/KRW 환율은 Naver -> Yahoo -> Frankfurter 순서로 재시도합니다.
- 실패가 남으면 앱 화면에 '2개 실패'만 표시하지 않고 실제 종목명을 표시합니다.
