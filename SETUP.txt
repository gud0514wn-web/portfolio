내 자산 포트폴리오 v31 / Apps Script v12
==========================================

[업데이트]
1. GitHub 저장소 루트의 파일을 이 ZIP 안의 파일들로 교체합니다.
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
2. Google Apps Script는 apps_script_price_proxy.gs(v12) 내용으로 교체합니다.
3. Apps Script 편집기에서 setupPortfolioSync()를 1회 실행합니다.
   - 기존 Portfolio Cloud Sync 시트가 있으면 그대로 사용하면서 History 시트를 추가합니다.
4. [배포] > [배포 관리] > 기존 웹 앱 수정 > 새 버전 > 배포합니다.
5. 기존 /exec URL은 같은 배포를 업데이트했다면 그대로 사용할 수 있습니다.

[자산변화 기능]
- 포트폴리오 / 자산변화 탭 추가
- 클라우드 동기화가 켜진 상태에서 새로고침 또는 자산 저장 시 History 시트에 기록
- 하루에 여러 번 기록돼도 그 날짜의 '총 평가자산 최고값' 한 건만 보관
- 더 높은 값이 들어오면 그 시점의 자산별 평가금액/비중도 함께 교체
- 막대그래프: 총자산
- 꺾은선: 평가손익
- 30일 / 90일 / 전체 범위 선택
- 일별 금액 오른쪽 화살표를 누르면 그 날 최고기록 시점의 자산별 금액 확인

[동기화]
- PC/모바일에서 자산 추가·수정·삭제 시 클라우드에는 즉시 저장
- 다른 기기 변경사항은 화면 맨 위에서 아래로 당겨 새로고침할 때 불러옴
- 1분 주기 자동 동기화는 사용하지 않음

[고정 헤더]
- 메인 상단 '내 자산 포트폴리오 / ₩ / 새로고침 / ⋯' 영역은 스크롤해도 고정
- 자산 추가 및 백업·설정 창의 제목/닫기 버튼도 창 안을 스크롤해도 고정

[중요]
- 자산변화 과거 기록은 기존 Assets 시트만으로는 복원할 수 없습니다.
- v31/v12 적용 후 처음 기록되는 날짜부터 일별 최고값이 누적됩니다.

[v32]
- 자산변화 탭의 '불러오기' 버튼이 모바일에서 두 줄로 깨지지 않도록 한 줄 고정.
- '자산 변화' 제목과 불러오기 버튼을 같은 줄에 두고, 설명문은 아래 전체 너비로 분리.
- 일별 자산금액 우측 펼침 버튼의 문자 화살표를 CSS형 V 화살표로 교체.
- 펼쳤을 때 화살표가 자연스럽게 위쪽으로 회전.
- 모바일 700px 이하에서 버튼/간격을 별도 보정.
- Apps Script는 v12 그대로 사용.

[v33]
- 자산변화 차트에서 막대그래프 제거.
- 평가손익 선 그래프 제거.
- 일별 총 평가자산만 단일 꺾은선 그래프로 표시.
- 데이터가 1일뿐이거나 변동폭이 작아도 선/포인트가 잘 보이도록 Y축 자동 여백 적용.
- Apps Script는 v12 그대로 사용.

[v34]
- 자산변화 차트를 다시 '총자산 막대 + 총자산 꺾은선' 조합으로 변경.
- 막대 꼭대기의 총자산 값들을 선으로 연결해 추세가 한눈에 보이도록 구성.
- 평가손익 선은 사용하지 않음.
- 그래프 아래 '선 · 총자산' 범례 문구 제거.
- Apps Script는 v12 그대로 사용.
